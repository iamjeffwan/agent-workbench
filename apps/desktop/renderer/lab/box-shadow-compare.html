box-shadow 对比

重点看 C：那才是「内部区域阴影」，不是上下边线。

A · 原版（边线式 inset）

上下各 1px，几乎没有模糊 → 看起来像描边，不是整块内部变暗。

边线式内部阴影
box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.82), inset 0 -1px 0 rgba(0, 0, 0, 0.12), 0 2px 5px rgba(0, 0, 0, 0.13), 0 0 30px rgba(0, 0, 0, 0.2);

B · 只加深边线

还是边上下手，只是更明显一点；外晕也减弱了。

更深的边线
box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.7), inset 0 -2px 3px rgba(0, 0, 0, 0.22), 0 2px 4px rgba(0, 0, 0, 0.12), 0 0 14px rgba(0, 0, 0, 0.08);

C · 内部区域阴影（你要的）

关键：inset + 较大模糊（可再加扩散）。阴影从四周向内晕开，整块像凹进去。

区域式内部阴影
box-shadow: inset 0 0 18px rgba(0, 0, 0, 0.18), 0 2px 4px rgba(0, 0, 0, 0.12), 0 0 14px rgba(0, 0, 0, 0.08);

D · 区域阴影再加重

模糊更大、颜色更深；也可加第 4 个数（扩散）让暗区更铺满。

更重的区域阴影
box-shadow: inset 0 0 28px 4px rgba(0, 0, 0, 0.22), 0 2px 4px rgba(0, 0, 0, 0.12), 0 0 12px rgba(0, 0, 0, 0.06);
边线式：偏移 1px、模糊约 0 → 只在边上画线。
区域式：偏移多为 0，模糊 12px+ → 阴影铺进内部区域。
公式：inset 水平 垂直 模糊 [扩散] 颜色 想更「凹」：加大模糊/扩散，或提高黑色透明度。
