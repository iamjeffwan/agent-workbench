# HTTP Toolkit UI source notice

The desktop renderer in this directory contains source and visual component
styles adapted from `httptoolkit/httptoolkit-ui`.

- Upstream repository: https://github.com/httptoolkit/httptoolkit-ui
- Upstream commit: `66488157be993c88152bf0b5964cfa1c63e0fbf5`
- Upstream license: `AGPL-3.0-or-later`
- Copyright: Tim Perry and HTTP Toolkit contributors

Copied areas include the application container, sidebar, theme, split pane,
event table, filter/footer, focused-row outline, HTTP detail cards, collapsible
sections, header grids, Monaco body viewer, icons, fonts and logo. The
upstream network model, account system and proxy state were replaced with
static local fixture data for this design-stage renderer.

The full upstream license text is included in
`LICENSE-AGPL-3.0-or-later.txt` in this directory.
