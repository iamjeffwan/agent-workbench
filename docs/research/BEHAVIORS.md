# Behavior inventory

## Reference behaviors

- The supplied HTTP Toolkit screenshots use a persistent master-detail layout.
- Rows use a left-edge status accent and a stronger neutral selected surface.
- The filter input supports typed predicates and an inline suggestion surface.
- Inspector sections expand vertically and preserve a monospace raw-data treatment.
- The live marketing site uses subtle hover elevation and a red-orange gradient for primary actions.

## Agent Workbench behaviors

- Clicking an execution row selects it and immediately updates the inspector.
- Clicking a collapsed exploration group reveals its children; clicking it again collapses them.
- Search matches step name, type, source, status, and summary text. `type:` and `source:` prefixes are supported.
- Source chips toggle one source filter at a time. The active filter is visually pressed.
- The clear action resets search and source filtering.
- Clicking a turn in the project drawer scrolls its group into view and marks it active.
- The inspector close action clears selection and returns to the contextual empty state.
- All transitions are 120–180ms and avoid motion that would reduce information-scanning speed.
