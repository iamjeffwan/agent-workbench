## 使用约定

- 本目录截图代表当时真实应用界面。
- `docs/design-references`（设计参考目录）中的图片只用于设计参考，不能作为当前实际界面依据。
- 分析或改造界面前，应优先查看本目录截图，并结合当前代码确认。
- 如果界面已经变化、截图缺少必要状态，或无法从现有截图确认，应直接请用户重新截图，不自行假设界面现状。
