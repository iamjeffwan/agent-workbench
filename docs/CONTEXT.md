# Agent 工作台

Agent 工作台帮助开发者观察编程代理的执行过程，并把代理操作、程序运行和代码变化放在同一条可追溯的记录中。

## Language

**工作台**：
独立于编程代理的只读观察界面。它读取代理和程序产生的记录，但不承接代理原有的对话、反馈或任务管理。
_Avoid_: 代理客户端、监控面板

**旁路观察**：
工作台在不接管代理的情况下，持续接收、关联并显示代理的执行记录。
_Avoid_: 指挥、控制、接管

**因果观察范围**：
以当前执行轮次作为默认归属范围，记录期间发生的项目文件变化和项目程序活动。重点是继续确定哪项代理操作引起了变化，以及变化前后的具体内容，不要求用户确认每项活动是否属于代理。
_Avoid_: 人工归属确认、通用项目监控

**执行记录**：
代理和程序实际产生的操作及结果，例如工具调用、命令、文件变化、程序请求和测试输出。
_Avoid_: 日志、聊天记录

**执行步骤**：
操作流中可单独选择和查看详情的一项实际活动，例如函数调用、文件修改、终端命令或网络请求。每个执行步骤包含用于列表展示的通用信息和该类型专属的完整详情。
_Avoid_: 原始事件、页面组件

**语义步骤**：
按照活动目的识别的执行步骤，例如模型调用、数据库操作或缓存操作。底层网络请求可以作为它的子步骤保留，但不替代上层含义。
_Avoid_: 通用网络请求

**执行轮次**：
用户向编程代理发送一次消息后，由代理产生的一轮连续执行。下一条用户消息会开始新的执行轮次，即使它们属于同一个代理会话。
_Avoid_: 开发任务、完整会话

**代理观察**：
记录编程代理直接发起的工具调用、终端命令、文件变化和执行结果。
_Avoid_: 程序内部追踪

**代理工具步骤**：
编程代理直接发起的一次工具调用。步骤名称使用代理提供的真实工具名称；由该工具启动的进程、函数和请求作为其子步骤显示。
_Avoid_: 程序活动、推测名称

**程序观察**：
记录代理所启动程序的内部运行过程，包括边界方法调用，以及网络请求、数据库操作和模型调用等外部活动。
_Avoid_: 代理操作记录

**项目函数**：
定义在被观察项目源码范围内并在运行时实际执行的函数。第三方依赖、框架内部和语言运行时函数不属于项目函数。
_Avoid_: 所有运行时函数、业务步骤

**边界方法**：
接口文件中的抽象方法所对应的具体实现方法。首版程序观察默认只记录这些方法，不记录其内部的局部辅助函数和第三方依赖函数。
_Avoid_: 全部项目函数、业务步骤

**值快照**：
边界方法开始和结束时，对参数、返回值或错误进行的只读记录。无法直接保存或体积过大的值使用摘要或引用表示；快照本身受深度、数量、字节和耗时上限约束。
_Avoid_: 实时对象、完整内存状态

**操作流**：
一个执行轮次内按发生时间排列的执行步骤。父子调用关系通过层级表达，但不改变整体时间顺序。
_Avoid_: 调用树、日志列表

**触发关系**：
一项观察操作直接引发另一项观察操作，例如终端命令启动程序、边界方法发出网络请求。主代理和子代理之间的组织关系不属于触发关系。
_Avoid_: 代理责任、代理组织结构

**追踪编号**：
代理工具调用侧的关联标识。启动进程时写入环境后，成为该进程的进程来源编号；项目函数不需要为此增加参数。
_Avoid_: 业务编号、系统环境配置

**进程来源编号**：
进程启动时由环境带入并随子进程继承的标识，说明是哪次代理工具调用启动了该进程。进程存活期间保持不变。
_Avoid_: 当前请求编号、业务事务号

**当前活动编号**：
进程启动后，由后续请求、消息队列任务或其他入口建立的活动标识，并沿这些传输通道自动传播。用来把本次执行挂到正确的后续触发来源，而不是挂到最初的启动命令。
_Avoid_: 进程 PID、仅按时间推测

**代码状态**：
某一时刻项目文件内容的确定版本，用来说明命令或程序活动实际运行在什么代码之上。
_Avoid_: 最终代码、提交版本

**测试后变化**：
测试开始前的代码状态与执行轮次结束时的代码状态之间的差异。两者不同时，工作台提示测试后代码发生过变化，并允许查看对应差异。
_Avoid_: 验证有效性、最终代码质量

**凭据秘密**：
能够直接用于身份认证或获得系统访问权限的数据，例如密钥、访问令牌、密码、会话凭据和数据库连接密码。
_Avoid_: 源码、提示词、请求正文、业务数据
